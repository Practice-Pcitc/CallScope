# 数据库与迁移

开发环境使用 SQLite；模型保留 PostgreSQL 驱动支持，但本次验证使用 SQLite。
`projects` 关联扫描任务、接口、图节点、图关系和 AI 结果，项目删除级联清理数据库记录，不删除目标源码。
扫描修订 ID 用于隔离新旧图，扫描成功后才切换活动版本。Repository 只 flush，Service 控制 commit/rollback。

从 backend 目录运行 `uv run alembic upgrade head`。已有数据库升级前自行备份，迁移不会重新初始化现有数据。
`20260909_0006` 为扫描、图和接口表补齐 updated_at，并为关联表补齐 created_at；已有记录回填迁移时间。
SQLite 读出的无时区值按数据库写入约定解释为 UTC，通过 Schema 输出带时区时间。

集成测试在临时数据库验证升级、降级及再次升级。单元/API 测试使用独立内存数据库，不读写开发库。
分析原始输入输出不持久化；结构化结果启动时按保留天数清理，删除项目立即级联清理。清理不等同于安全擦除已有磁盘备份。
