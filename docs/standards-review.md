## 根据现有项目适配或不适用

- React 保留：函数组件、hooks、Zustand、React Router 分别承担 Vue 规范中的对应职责。
- CallScope 目录大小写、alembic/、api/routes/、pages/ 等有明确含义的现有名称保留，避免仅为示例结构移动。
- 无 RAG、MCP、会话记忆、自主工具执行，不创建空目录或假接口。
- 无登录、多租户或上传功能，密码哈希、用户权限、上传限制不作为已实现能力；严格限定单用户本机运行。
- 无公网部署需求，不增加 Docker/生产部署流程；本次增加 CI，保留本地启动方式。
- 未选择开源许可证，不擅自替维护者授予代码许可。
- 未接入 SSE/WebSocket，长任务使用状态查询；客户端取消等待不等于取消服务器模型任务。
